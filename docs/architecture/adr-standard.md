# Architecture Decision Record (ADR) Standard

**Status:** DRAFT | **Version:** 0.1.0

Use one ADR per material architecture decision. Store the accepted ADR in the governed project's code repository; link the governance/approval record from Notion.

Required sections:
1. ADR ID, title, project ID, version and status (PROPOSED, ACCEPTED, SUPERSEDED, REJECTED).
2. Context and decision drivers.
3. Constraints and quality attributes.
4. Options considered (including do nothing).
5. Decision and rationale.
6. Consequences, trade-offs and risks.
7. Security, privacy, data and operational impact.
8. Migration, compatibility and rollback.
9. Approvers and linked Decision ID.
10. Supersedes / superseded by.

An ADR marked ACCEPTED does not itself grant implementation, production or release permission.
